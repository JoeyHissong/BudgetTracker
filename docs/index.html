A simple, local-only app for tracking recurring monthly bills. No sign-up, no cloud, no ads — just your bills.

Features

🧾

Recurring bills

Add bills once with a due day and category, and they roll forward every month automatically.

✅

Mark as paid

Tap a bill to mark it paid for the month and watch your remaining balance update instantly.

📊

Monthly summary

See total due, total paid, and what's left at a glance, broken down by month.

💱

Multi-currency

Choose the currency that matches your budget from the settings panel.

🔒

Private by design

Everything is stored locally on your device. No account, no server, no tracking.

📱

iOS & Android

Built with React Native so it runs natively on both platforms from one codebase.

🔒 Budget Planner stores all data locally on your device using AsyncStorage. Nothing is sent to a server, and the app works entirely offline.

Get started

  1. Clone the repository and install dependencies
git clone https://github.com/JoeyHissong/BudgetTracker.git
cd BudgetTracker
npm install
  1. Start Metro, then run the app on your platform of choice
npm start
# in a separate terminal
npm run ios      # or
npm run android
  1. See the README for environment setup details.
